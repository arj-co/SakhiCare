# SakhiCare OpenAPI Endpoints

- \`GET /health\`: Service health probe
- \`POST /sync/batch\`: Sync offline maternal assessments
- \`POST /api/v1/speech-llm/process-transcript\`: Speech-LLM unified reasoning
- \`POST /api/v1/speech-llm/process-audio\`: Multipart audio file ingestion
- \`POST /api/v1/ai/copilot\`: SakhiAI conversational copilot
- \`POST /api/v1/ai/counseling-script\`: Vernacular family persuasion generator
- \`POST /api/v1/ai/differential-diagnosis\`: Medical Officer clinical notes
- \`GET /fhir/export/{patient_id}\`: HL7 FHIR R4 Bundle resource
